# Monitoramento de Chuvas - Recife 🌧️

Dashboard interativo desenvolvido em Python para o monitoramento de dados pluviométricos na cidade do Recife. O projeto consome dados públicos da API da APAC (Agência Pernambucana de Águas e Clima) e oferece visualizações em tempo real para auxílio na análise de riscos ambientais.

## 🚀 Tecnologias Utilizadas
- **Python**: Linguagem de programação principal.
- **Streamlit**: Framework para construção do dashboard web.
- **Pandas**: Manipulação e tratamento de dados (Data Wrangling).
- **Plotly**: Visualização de gráficos interativos.
- **Streamlit Cloud**: Hospedagem da aplicação.

## 📋 Funcionalidades
- Integração em tempo real com a API da APAC.
- Filtragem automática de dados para o município do Recife.
- Visualização de acumulado de chuvas por hora.
- Interface responsiva e acessível via navegador.
